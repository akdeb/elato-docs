Muse Glimmer models from [`mlx-community`](https://huggingface.co/mlx-community) work with OpenToys. The README lists **Muse Glimmer 30B**. Paste the repo name into the **Models** page to switch.

<Note>
  Muse picks a reply channel before it answers. OpenToys sends its reply straight to the user so the token budget goes to speech and not to hidden reasoning.
</Note>
