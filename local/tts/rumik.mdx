| **Model** | `rumik-ai/rumik-oss-1-mlx-4bit` |
| **Memory** | About 3 GB RAM, 2 GB on disk |
| **Quality** | Indic |
| **Languages** | 22 Indic languages plus English |
| **License** | Non-commercial |

Replies come in the language the user speaks, written in that language's native script. Characters can use the cues `<laugh>`, `<chuckle>` and `<sigh>`.

<Note>
  The 4-bit build is experimental.
</Note>
