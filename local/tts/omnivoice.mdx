| | |
|---|---|
| **Model** | `mlx-community/OmniVoice-bf16` |
| **Memory** | About 4 GB RAM, 2 GB on disk |
| **Quality** | Multilingual |
| **Languages** | 646+ |
| **Voice cloning** | Yes, zero-shot |

Small and fast, with the widest language coverage of any backend here.

Characters can use the cues `[laughter]` and `[sigh]`.
