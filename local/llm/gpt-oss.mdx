gpt-oss models from [`mlx-community`](https://huggingface.co/mlx-community) work with OpenToys. The README lists **gpt-oss 20B**. Paste the Hugging Face repo name into the **Models** page to switch.

<Note>
  It is a large model. Check you have the memory to spare before switching, since a heavy LLM slows every reply.
</Note>
