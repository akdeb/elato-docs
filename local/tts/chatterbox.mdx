description: "Chatterbox-turbo is an alternative local text-to-speech and voice cloning backend for OpenToys."
---

| | |
|---|---|
| **Model** | `mlx-community/chatterbox-turbo-fp16` |
| **Role** | Alternative TTS backend |
| **Memory** | About 6 GB RAM, 4 GB on disk |
| **Voice cloning** | Yes, from a reference clip |

Characters can use the cues `[laugh]`, `[chuckle]`, `[sigh]`, `[gasp]`, `[cough]`, `[clear throat]`, `[sniff]`, `[groan]` and `[shush]`.

Select it on the **Models** page. The backend can be swapped live.
