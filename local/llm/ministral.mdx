---

`mlx-community/Ministral-3-3B-Instruct-2512-4bit` is the default LLM in OpenToys. At 3B parameters and 4-bit quantization it is small enough to answer quickly on any Apple Silicon Mac, which is what a talking toy needs.

<Note>
  Downloaded on first setup. Afterwards it runs offline.
</Note>

To use a different model, see [Choosing an LLM](/local/llm/overview).
